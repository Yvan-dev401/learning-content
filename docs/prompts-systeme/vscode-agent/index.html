À quoi sert ce prompt#

Son rôle
Décliner un même agent selon plusieurs modes de l'éditeur.
Quand il est envoyé
À l'ouverture d'une conversation dans l'éditeur, avant votre premier message — puis renvoyé à chaque échange, avec le contexte du fichier en cours.
Ce qu'il produit
Selon le mode : une réponse dans le panneau, une édition appliquée, ou une suite d'actions.

Première visite ? Commencez par le guide : ce qu'est un prompt système, quand il est envoyé et ce qu'il coûte.
