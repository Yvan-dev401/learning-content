Ajouter un dépôt#

La liste ci-dessus est complète : comparer l'URL suffit à savoir si un dépôt est déjà intégré. Pour en ajouter un quatrième, quatre pièces sont nécessaires.

  1. Un script tools/ingest_<source>.py qui clone le dépôt et produit un manifeste dans content/.
  2. Un adaptateur d'une vingtaine de lignes dans Site.register_items(), pour que le contenu entre dans le catalogue, les sujets et la recherche.
  3. Une entrée dans COLLECTIONS (tools/build.py) : icône, libellé, verbe, URL.
  4. Un fichier de métadonnées françaises, et une entrée dans ce fichier content/_sources.json.

La licence du dépôt compte autant que son contenu : ce site est une compilation à licences mixtes, chaque partie restant sous la sienne.
